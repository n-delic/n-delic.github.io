Desktop Audio Studio

sevdah.

A studio-grade desktop audio player and streaming studio for Google Drive & Local Storage.

Go 1.22+ Wails v2 Vue 3 + TS Vuetify 3 SQLite MIT License
GitHub Repository ↗ Explore Features ↓

01. core features

Streaming & Storage

Dual Source Engine

Seamlessly switch between your local offline library and high-fidelity streaming directly from Google Drive.

Performance

Fast Extraction

Reads ID3 & FLAC metadata, tags, and embedded album cover art in milliseconds without downloading full media files.

DSP & Audio

Studio Audio Engine

Integrated 10-Band EQ, gapless audio playback, smooth crossfading, and real-time loudness normalization.

Visuals

Ambient UI

A dynamic, modern dark interface that dynamically adapts its ambient glow and color accents to your current album artwork.

Integration

Native Media Controls & Discord RPC

Integrated with Linux MPRIS, Windows SMTC, physical hardware keys, and live Discord Rich Presence.

Sync & Experience

Cloud Playlists & Synced Lyrics

Synchronize custom playlists across machines and sing along with real-time synchronized .lrc lyrics in Now Playing mode.

02. tech stack & architecture

Core Engine

  • Application Bridge: Wails v2
  • Backend: Go 1.22+ (HTTP Proxy, OAuth, MPRIS, Discord RPC)
  • Cache / Database: SQLite (High-speed local cache & state)

Client UI

  • Framework: Vue 3 + TypeScript
  • UI Components: Vuetify 3
  • Audio Context: Web Audio API + Custom DSP nodes
